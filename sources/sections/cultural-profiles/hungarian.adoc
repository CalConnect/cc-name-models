
// from 2006 Naming guide
=== Hungarian

name components:

- given name
- family name

==== Typical name patterns

|===
|family name|given name
|===

==== Examples

[example]
Kovács János

[example]
====
If there is more than one given name, they come in order of importance
after the family name:

- Kovács János Aladár
====

[example]
====
There can be more than one family name, which can be written fully or abbreviated
into initials:

- Segesdy Kovács János
- Segesdy-Kovács János
- S.Kovács János
- Segesdy K. János
====
