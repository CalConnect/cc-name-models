=== Pseudonym

A pseudonym or alias is a name that a person or group assumes for a particular
purpose, which can differ from their given name(s).

* Art name
* Stage name
* Nickname
* Username
* Pen name
* Alias
* Code name
* Regnal name

////
Pseudonyms include stage names and user names, ring names, pen names,
nicknames, aliases, superhero or villain identities and code names, gamer
identifications, and regnal names of emperors, popes, and other monarchs.
////

=== Family name

==== General

The family name is the portion of a personal name that indicates a person's family
(or tribe or community, depending on the culture).

Depending on the culture, all members of a family unit may have identical family names or there may be variations based on the cultural rules.

NOTE: Not all cultures provide a family name in a personal name.

[alt]#last name#

==== Compound family name

A compound family name is one based on merged family names.

==== Icelandic name

==== Patrilineal family name

A patrilineal family name is a name originated from the family name of the father.

==== Matrilineal family name

A matrilineal family name is a name originated from the family name of the mother.

A matronymic name is a name originated from one of the name components of the
mother or a matrilineal ancestor.

Different cultures have different ways of producing matronymic family names.

==== Patronymic

A patronymic name is a name originated from one of the name components of the
father or a patrilineal ancestor.

Different cultures have different ways of producing patronymic family names.

[example]
Mongolian: Otryadyn Gündegmaa, O. Gündegmaa, Otryadyn is the patronymic family name

=== Genonymic

A genonymic name is a name derived from one of the name components of an ancestor.

NOTE: the genonymic could come from a parent, grandparent or an earlier ancestor.

=== Avonymic

An avonymic name is a name derived from one of the name components of a grandfather.

=== Paedonymic

An paedonymic name is a name derived from one of the name components of a child.


=== Religious name

A religious name is a name or title given to, or used by, a person according to
the tradition of the person's religion.

=== Title

A title is a name that describes a position or job.


==== Maiden name

A maiden name is a family name that a married woman used prior to its being
changed at marriage.



==== Mononymous

Some personal names are known and addressed by a single given name.

In some areas of the world, many people are known by a single
name, and so are said to be mononymous.

NOTE: Mononymic name is considered as a given name without a family name.

[example]
Thant, third Secretary-General of the United Nations.

=== Given name


Diagram of naming conventions, using John Fitzgerald Kennedy as an example.

The sarcophagus of Queen Desideria at Riddarholm Church in Sweden. The name was
given to Desideria Clary not at birth but when she was created Crown
Princess of Sweden in 1810.

A given name is usually is given to a person, normally to a child by
his or her parents at or close to the time of birth.

By contrast, a family name (also known as a family name, last name, or gentile
name), which is normally inherited, is typically shared with other members of
one's immediate family. Regnal names and religious or monastic names are
special given names bestowed upon someone receiving a crown or entering a
religious order. Such a person then typically becomes known chiefly by that
name.

NOTE: There could be more than one given name in a personal name.

==== Middle name

A middle name is a given name in some cultures that is not a first name or a
family name.

==== Others

==== Arabic name

Arabic names were historically based on a long naming system; most
Arabs did not have given/middle/family names, but a full chain of
names. This system was mainly in use throughout the Arab world.

* Ism, given name, first name or personal name
* Laqab, family name, nickname, title, honorific
* Nasab, patronymic series
* Nisbah, family name
* Kunya, teknonym (name of first son or daughter) or nickname

===== Papal name

A papal name or pontificial name is the regnal name taken by a pope.

Both the head of the Catholic Church, usually known as the Pope, and the Pope of the Coptic Orthodox Church of Alexandria (Coptic Pope) choose papal names.

[example]
John Paul II.

=== Nickname

A nickname is a familiar name given to a person instead of or as well as the
real personal name.

[example]
The given name "`Mikhail`" in Russian often goes by the nickname "`Misha`".

[example]
The given name "`José`" in Spanish often goes by the nickname "`Pepe`".

[example]
The given name "`William`" in English often goes by the nickname "`Bill`".
